# Asistente-de-deposito-con-IA
Módulo de consulta con IA (SQL + Node.js + React). Permite preguntarle al depósito en lenguaje natural —desde una sola caja de texto— sobre ubicación de productos, contenido de cada calle del galpón y mercadería vencida, y muestra la respuesta sobre un plano interactivo del depósito.
